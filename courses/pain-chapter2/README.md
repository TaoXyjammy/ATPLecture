# 第二章 疼痛的运动康复评定

依据本次上传《疼痛.pdf》章首页及第15—19页，采用本次《肌骨概述.pptx》的白底橙红模板，27页，16:9。

- [可编辑PPT](Chapter2_Pain_Assessment.pptx)
- [PDF预览](Chapter2_Pain_Assessment.pdf)
- [逐页讲解备注](逐页讲解备注.md)
- [教材顺序核对](顺序核对.json)
- [制作源文件](Pain_Chapter2_Source.zip)

内容顺序：第一节疼痛概述（评估概述、分类）；第二节疼痛评定方法（病史、部位、性质、程度、发展进程、加重缓解因素、结果记录）。四种评分方法按VAS、NRS、VRS、FPS的教材顺序排列。

补充了IASP 2020定义、操作示意、虚构教学案例和课堂练习，均标明为补充或教学案例。正文为中文；量表缩写与SAND保留以便学习。VAS线段为教学示意；FPS页讲解使用步骤，不将自绘表情充作标准量表。正文、框图与量表教学示意可编辑；模板封面原装饰图保留。

每页有演讲者备注；Markdown另行提供。普通运动情境为主，足球作为可选例子。课件无临床诊断替代用途。

## 源文件重建

安装 Python 3 与 python-pptx，解压源文件后执行：

```bash
python -m pip install python-pptx
python source/build_pain.py
```

字体：Noto Sans CJK SC，其他电脑可换成思源黑体或微软雅黑。PDF已嵌入用于预览的字体。模板来自用户提供，仅随本课件用于编辑与重建。未将教材扫描全文加入公开仓库。
