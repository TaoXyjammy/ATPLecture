## 范围与顺序

依据用户上传《骨骼肌.pdf》，书名页标示《运动生理学》（第6版），第二章“运动与骨骼肌”，第一节第12—18页。

一、骨骼肌的超微结构及肌丝滑行学说：

1. 肌原纤维和肌小节
2. 肌管系统
3. 肌丝的分子组成（粗肌丝→细肌丝）
4. 肌丝滑行学说

二、骨骼肌细胞的生物电现象：

1. 静息电位
2. 动作电位（变化过程→产生原理）
3. 兴奋性变化过程，继而学习动作电位三个特点
4. 动作电位的传导

保留教材前置的肌肉、肌束、肌纤维层级介绍。止于第二部分，不讲第三部分“神经—肌肉接头的兴奋传递”和第四部分“兴奋—收缩耦联过程”。最后附复习与课堂练习。
