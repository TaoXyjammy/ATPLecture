## 本次修改

正文按教材原句和原有顺序整理，仅作分段、分页及字号排版；统一括号、空格、范围符号与离子上下标的显示方式，不将原句改写成概括句。第一节开头的肌纤维、肌腹和肌腱说明一并保留。

恢复教材用语，如“肌原纤维和肌小节”“锋电位”“兴奋性的变化过程”；恢复原文中的结构组成、长度范围、离子浓度倍数、通透性比例等内容。

图名与图下注释采用原文。图2-6与图2-7恢复a、b、c、d及原图注；删除上一版新增的解释性图内配文和钠钾泵计数说明。保留彩色结构重绘、彩色曲线与原生中文标注。

原先自行归纳的问答标题、总结句、课堂练习和扩展说明已从正文移除。PPT演讲者备注同样使用对应教材段落与图注。

## 校对与文件

使用扫描原页逐段核对文字，重点核对希腊字母、离子符号、单位、数值及跨页续文。对PPT与导出PDF进行正文完整性检查，确认各段文字均能在PDF中提取。

原文文字表见`source/textbook_text.json`。结构图2-1—2-3沿用上一版参考教材生成的彩色结构图；中文标注为PPT可编辑文字。图2-4—2-7根据原图标签重新绘制。曲线是教材形态的教学重绘，不是实验实测数据，图内横轴沿用教材“时间（ms）”且不添加数值刻度。
